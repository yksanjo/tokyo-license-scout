# Tokyo License Scout

A browser strategy game about scouting small Japanese IP owners. Walk the
backstreets of the fictional neighborhood of Nekomachi, find the six hidden
IP owners, and sign them with the right offer before the rival agency does.
Sixteen days per run.

Play it live: https://yksanjo.github.io/tokyo-license-scout/

Single-file vanilla HTML/CSS/JS. No build step, no dependencies. Nekomachi
and all studios, characters and catalogs are fictional.
